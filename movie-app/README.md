# MovieHub

A movie and series browser for Android, powered by two sources:

- **MOVI.PK** — Hindi movies with streaming and download links
- **MultiMovies** — Movies, TV series and anime with multi-server playback

MovieHub is a WebView-based Android app. The web layer (React + Vite) handles
all browsing, detail pages and source parsing. A native Java bridge fetches
pages directly (bypassing CORS) and handles downloads via the system DownloadManager.

## Features

- Browse featured movies from both sources on the home screen
- Filter by type (movie/series) and genre
- Open a detail page with synopsis, rating, cast and genres
- Play movies — MultiMovies opens its built-in multi-server player, MOVI.PK
  opens the ardance.org stream
- Browse series by season and episode, then play any episode
- Search across both sources
- Download movies via the Android DownloadManager

## How it works

1. The web app fetches movie pages from the sources at runtime.
2. In the Android app, a native bridge (`MokuBridge.request(url)`) fetches
   HTML on a background thread and returns it to JavaScript — this bypasses
   CORS restrictions that would block direct browser fetches.
3. In a plain browser (for testing), the app falls back to a CORS proxy.
4. When you tap Play, the watch URL loads in the WebView. For MultiMovies
   this is the site's own player page; for MOVI.PK it's the ardance.org stream.
5. Download links trigger the native DownloadManager.

## Adding more sources

Add a new entry to `SOURCES` in `src/sources.js`, then write an adapter with:
`fetchHome()`, `fetchList(type, filters)`, `fetchDetail(url)`, `fetchSearch(query)`,
and optionally `fetchEpisodes(url)` for series. The parsing helpers in `api.js`
(`fetchHtml`, `parseHtml`, `absoluteUrl`, `extractYear`, `extractRating`) make
this straightforward.
